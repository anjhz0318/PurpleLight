# Bilibili Video Intelligence Skill
Run `python3 ./scripts/bili_sub.py "<url_or_bvid>"` via `bash` from the PurpleLight project root (or `python3 "$(dirname "$SCOUT_WORKSPACE")/../scripts/bili_sub.py" "<url_or_bvid>"`) to extract video metadata, CC/AI subtitles, and top comments.
